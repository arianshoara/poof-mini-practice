# چک‌لیست تست دستی پروژه

این فایل نتیجه‌ی آزمایش‌های دستی پروژه را پیش از انتشار هر نسخه ثبت می‌کند.

## معنی علامت‌ها

- `[ ]` هنوز آزمایش نشده یا درست کار نکرده است
- `[x]` آزمایش شده و درست کار می‌کند
